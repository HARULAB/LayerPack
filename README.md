# LayerPack

AviUtl2 の現在のシーンで、空のレイヤーを飛ばしてオブジェクトを上へ詰めるプラグインです。`LayerPack` パネルの「空レイヤーを圧縮」ボタンから実行できます。従来の編集メニュー「LayerPack → 空レイヤーを圧縮」も使えます。どちらも同じ確認画面を表示し、一回の編集操作で適用します。

## インストールと使い方

1. AviUtl2 を終了します。未保存のプロジェクトがあれば先に保存してください。
2. 配布ZIP内の `LayerPack.aux2` を AviUtl2 の `Plugin` フォルダに置きます。既存版を更新するときは、古いDLLを別の場所に退避してください。テスト用の `LayerPackHostSmoke.aux2` は入れないでください。
3. AviUtl2 を起動し、初回の信頼確認が表示された場合は内容を確認して許可します。`LayerPack` パネルを表示してボタンを押すか、編集メニューから実行します。
4. 確認画面で、移動するレイヤーと調整する制御範囲を見てから実行します。最初はプロジェクトのコピーで、見た目・Undo/Redo・保存後の再読込を確かめてください。

パネルはAviUtl2のウィンドウ管理に登録されます。閉じた後はAviUtl2のウィンドウ表示メニューから再表示できます。プロジェクトは自動保存しません。

## 制御範囲の保護

- グループ制御・カメラ制御の「対象レイヤー数」が正の整数なら、移動後も元と同じ下位オブジェクトを対象にするよう数値を再計算します。
- `0`（下位全体）はそのまま維持します。
- 有限範囲に対象が一つもなく、そのさらに下にオブジェクトがある場合は、範囲の境界として空レイヤーを一つ残します。この空レイヤーは圧縮しません。
- 名前付き・非表示・ロック中のレイヤーは位置を固定します。そこにあるオブジェクトも移動しません。
- 未対応の「対象レイヤー数」を持つオブジェクトや、読めない設定値があるシーンは、変更せず中止します。

## 注意

現時点では開発版です。実プロジェクトで使う前にコピーで試してください。サードパーティ効果が独自の数値レイヤー参照を持つ場合、それを追跡する機能はまだありません。レイヤーの効果設定など、SDKで列挙できないレイヤー固有データは移動先へ複製しません。実行後は表示、Undo/Redo、保存・再読込を確認してください。

このプラグインは明示的に選んだ現在のシーンだけを編集します。

テスト用の `LayerPackHostSmoke.aux2` は本番用プラグインではありません。試験環境で自動的にオブジェクトを作るため、通常の環境へ入れないでください。配布・インストール対象は `LayerPack.aux2` のみです。

## ビルド

MSVC、CMake、AviUtl2 SDK が必要です。既定では同じ開発フォルダ内の SceneShelf に同梱された SDK ヘッダーを参照します。他の SDK を使う場合は `-DAVIUTL2_SDK_DIR=...` で指定します。

```powershell
cmake -S . -B build -G "Visual Studio 18 2026" -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

## 確認状況

- 計算テスト：空レイヤー、入れ子の制御範囲、対象なしの有限範囲、名前付き／ロック等の固定レイヤー、ランダム生成した構成を確認。
- SDK呼び出しのモックテスト：グループ制御・カメラ制御の値取得、移動、再設定を確認。
- AviUtl2 の隔離環境：両制御オブジェクトを作り、圧縮後のレイヤーと対象レイヤー数を読み戻し、保存・再読込後も維持されることを確認。
- パネル：ボタンの生成・クリック経路をモックテストで確認。隔離環境で新DLLの読み込みを確認。
- まだ未確認：実際のパネル画面での手動操作、Undo/Redo、実際の映像の見た目、サードパーティ効果の独自レイヤー参照。
