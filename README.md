# LayerPack

AviUtl2 の現在のシーンで、空のレイヤーを飛ばしてオブジェクトを上へ詰める汎用プラグインです。編集メニューの「LayerPack → 空レイヤーを圧縮」から実行します。実行前に移動数を確認し、一回の編集操作で適用します。

## 制御範囲の保護

- グループ制御・カメラ制御の「対象レイヤー数」が正の整数なら、移動後も元と同じ下位オブジェクトを対象にするよう数値を再計算します。
- `0`（下位全体）はそのまま維持します。
- 有限範囲に対象が一つもなく、そのさらに下にオブジェクトがある場合は、範囲の境界として空レイヤーを一つ残します。この空レイヤーは圧縮しません。
- 名前付き・非表示・ロック中のレイヤーは位置を固定します。そこにあるオブジェクトも移動しません。
- 未対応の「対象レイヤー数」を持つオブジェクトや、読めない設定値があるシーンは、変更せず中止します。

## 注意

現時点では開発版です。実プロジェクトで使う前にコピーで試してください。サードパーティ効果が独自の数値レイヤー参照を持つ場合、それを追跡する機能はまだありません。レイヤーの効果設定など、SDKで列挙できないレイヤー固有データは移動先へ複製しません。実行後は表示、Undo/Redo、保存・再読込を確認してください。

このプラグインは明示的に選んだ現在のシーンだけを編集します。プロジェクトを自動保存しません。本番環境には自動インストールしません。

テスト用の `LayerPackHostSmoke.aux2` は本番用プラグインではありません。試験環境で自動的にオブジェクトを作るため、通常の環境へ入れないでください。配布・インストール対象は `LayerPack.aux2` のみです。

## ビルド

MSVC、CMake、AviUtl2 SDK が必要です。既定では同じ開発フォルダ内の SceneShelf に同梱された SDK ヘッダーを参照します。他の SDK を使う場合は `-DAVIUTL2_SDK_DIR=...` で指定します。

```powershell
cmake -S . -B build -G "Visual Studio 18 2026" -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

- SDK呼び出しのモックテスト：グループ制御・カメラ制御の値取得、移動、再設定を確認。
- AviUtl2 の隔離環境：両制御オブジェクトを作り、圧縮後のレイヤーと対象レイヤー数を読み戻し、保存・再読込後も維持されることを確認。
